# Spendwise
SpendWise — Student Expense Analyzer

Track your money. Understand your habits. Spend smarter.

SpendWise is a modern, student-focused expense management and analysis application designed to help students track their spending, understand financial patterns, manage budgets, and build better saving habits.

Features
Expense Management
Add, edit, and delete expenses
Upload expenses through CSV/TXT files
Automatic expense categorization
Search, filter, and sort transactions
Add payment methods, notes, dates, and recurring status
Attach and preview receipts
Financial Analytics
Total spending and transaction overview
Category-wise spending analysis
Spending trends and patterns
Daily and monthly analysis
Weekday vs. weekend comparison
Highest-spending days
Interactive spending visualizations
Financial Health score
Budget Management
Set monthly budgets
Create category-wise budgets
Monitor budget utilization
Track spending against limits
Receive budgeting insights
Savings & Recurring Expenses
Create and track savings goals
Set target dates and monthly savings requirements
Track subscriptions
Monitor recurring expenses
Understand recurring spending commitments
Insights & Engagement
Rule-based Money Coach
Personalized spending insights
"Where Did My Money Go?" analysis
Monthly financial reviews
Student challenges
Achievements and progress tracking
Spending calendar
Reports & Data
Generate spending reports
Export expense data as CSV
Review monthly and category-based spending
Manage application data and preferences

Privacy

SpendWise follows a local-first approach. User expense information and application preferences are stored locally in the browser, allowing personal expense data to remain on the user's device.

Getting Started
Prerequisites
Node.js
npm
Installation
git clone <your-repository-url>
cd spendwise
npm install
npm run dev

Open the local development URL displayed in the terminal.

Production Build
npm run build

The production files will be generated in the dist directory.

Project Objective

The objective of SpendWise is to provide students with an interactive platform to track expenses, understand spending behaviour, manage budgets, set savings goals, and improve financial awareness.
