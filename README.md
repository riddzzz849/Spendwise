# Spendwise
SpendWise
Student Expense Analyzer

Track your money. Understand your habits. Spend smarter.

SpendWise is a modern student-focused expense analyzer designed to make personal finance easier to understand. It helps students record and categorize their expenses, visualize spending patterns, manage budgets, set savings goals, and gain useful insights into their financial habits — all through a clean and interactive interface.

About the Project

Students often manage expenses across food, travel, shopping, subscriptions, education, and everyday activities without having a clear picture of where their money is going. SpendWise addresses this problem by bringing expense tracking and financial analysis into one simple platform.

Users can add expenses manually or upload expense data, after which SpendWise organizes the information and presents it through interactive dashboards, charts, spending trends, budget tracking, and personalized insights.

The application is designed not just to record expenses, but to help users understand their spending behaviour and make more informed financial decisions.

What SpendWise Offers
Smart Expense Tracking

SpendWise allows users to maintain their expenses in one place. Transactions can be added manually or imported through CSV/TXT files. Expenses can be categorized, edited, deleted, searched, filtered, and sorted, making it easy to maintain an organized financial record.

Interactive Financial Analytics

The application transforms expense data into visual information that is easier to understand. Users can explore category-wise spending, daily and monthly trends, spending patterns, highest-spending days, weekday versus weekend behaviour, and an overall Financial Health score based on their available data.

Budget & Savings Planning

SpendWise helps users set monthly and category-based budgets and monitor how their spending compares with those limits. Users can also create savings goals, set target dates, track progress, and understand the amount they need to save each month.

Subscriptions & Recurring Expenses

Regular payments can easily become overlooked. SpendWise provides dedicated tracking for subscriptions and recurring expenses, helping users understand their ongoing financial commitments.

Personalized Insights

The built-in Money Coach uses rule-based analysis of spending behaviour to generate personalized observations and suggestions. Monthly reviews and the "Where Did My Money Go?" section provide a clearer picture of how money is being spent over time.

Student Engagement

SpendWise makes financial tracking more engaging through spending challenges, achievements, progress tracking, and a calendar-based view of daily expenses.

Reports & Data

Users can review their spending through monthly and category-based reports and export their expense information as CSV for further analysis or record keeping.

Technology

SpendWise is built using a modern frontend stack with React, TypeScript, Vite, and CSS. Expense information and application preferences are persisted using browser Local Storage, allowing the application to work without requiring a traditional external database for personal expense records.

Privacy

Privacy is an important part of SpendWise's design. Personal expense information is stored locally in the user's browser rather than being sent to an external database. This local-first approach allows users to manage their financial information directly on their device.

Design

SpendWise follows a modern fintech-inspired design while keeping the experience approachable for students. The interface combines clean information hierarchy, interactive visualizations, responsive layouts, premium gradients, subtle animations, and focused navigation to make financial information easier to explore.

Getting Started

Clone the repository and install the required dependencies:

git clone <your-repository-url>
cd spendwise
npm install

Start the development server:

npm run dev

To create a production build:

npm run build

The production-ready application will be generated in the dist directory.

Future Scope
