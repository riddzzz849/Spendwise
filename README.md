# SpendWise — Student Expense Analyzer

### Track your money. Understand your habits. Spend smarter.

SpendWise is a student-focused expense analysis web application designed to help students understand where their money goes. Users can upload monthly expense data in CSV or text format, enter expenses manually, and get categorized spending summaries, visual analytics, budgeting insights, and simple recommendations for better money management.

The application combines expense tracking with an intuitive financial dashboard so that raw transaction data becomes easier to understand and act on.

---

## About the Project

Managing daily expenses as a student can be difficult when spending is spread across food, travel, education, subscriptions, shopping, and other activities.

SpendWise provides a simple way to organize and analyze these expenses.

Instead of only displaying a list of transactions, the application turns expense data into meaningful information such as:

- Total money spent
- Number of transactions
- Average expense
- Major spending categories
- Spending trends
- Daily and monthly patterns
- Budget usage
- Savings progress
- Recurring expenses
- Subscription costs
- Personalized spending observations

The goal is to make financial information easier to understand without requiring complicated financial tools.
